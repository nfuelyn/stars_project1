## 1. Sans 不位移 ⇒ 菜单框**只加宽**，不改 y / 不改高

Sans 的 y 是**由框顶推导**的（`core.lua` renderWorld）：

```
Sans.y = 框顶 − 16 − SANS_H(148)
```

所以只要**框顶不变**，Sans 就一动不动 ✓。于是菜单长框改为：

```
我方行动（menu / sub / attack）时的框 = 宽 575，x 33..608
                                      y / 高 = 沿用上一回合的框（顶、底都不动）
```

| 上一回合框（y..底, 高） | 菜单框（只改宽） | Sans y | Sans 位移 |
|---|---|---|---|
| 33..608, 251..391, h=140（多段/骨刺常见） | 33..608, 251..391, **h=140** | 251−164 = **87** | **0** ✓ |
| 241..406, 226..391, h=165（终盘/螺旋3） | 33..608, 226..391, **h=165** | 226−164 = **62** | **0** ✓ |
| 420×260（内置大框，y=178.5） | 33..608, 178.5..438.5, **h=260** | 178.5−164 = **14.5** | **0** ✓ |

- **面板宽**：575−16 = **559**（行名区 = 559−40 = **519px**，见 §2/§3）；
- **不动 y/高** ⇒ Sans、菜单按钮行（按框底算 → 432）、框底全部不动 ✓；
- 敌人回合照旧由 `startEnemy()` 用脚本 zone 重设 ✓（不受影响）。

> 与上一版方案的差别：上一版我把框固定成 575×165（会改框顶 → Sans 跟着动）。按你这条口径，**改成"只加宽"**，Sans 零位移。

## 4. 食物栏滚动 —— **可以**，两种做法

### 方案甲：滚动视窗（连续滚动，推荐）

- 固定显示 **N 行**（`N = clamp(floor(行区 / 行高), 3, 8)`），选中项超出视窗时视窗自动跟随；
- 输入**不用加键**：现有 `↑↓`（`subMove`）改选中项，视窗跟着走 ✓（触屏：点行选择 + 面板边缘上下滑动可选做）；
- 右侧/底部加提示：`▲ 还有 2 项` / `▼ 还有 3 项`（或画一条细滚动条）；
- 当前 5 件物品、框高 140/165 时：行区 90/115px → **5 行刚好能全显示**（18px/行）⇒ 只有"物品变多"或"框更矮"时才真正滚动 ✓。

### 方案乙：分页（原版 BTS 的做法）

- 每页 4 格（2×2 网格）+ 左右翻页（`PAGE 1/2`）——原版就是这个（`Battle.xml` L2359-2422：第 5 格起画在 `x=640+…` 处）；
- 优点：与原版一致；缺点：中文名一列 4 行更宽，网格要重排，改动比滚动大。

**建议**：走**方案甲**（滚动），并对"提示条"用最小的两行文字实现；将来物品 > 8 件也不用再改结构。

### 实现位置（3 处）

| # | 文件 | 改动 |
|---|---|---|
| 1 | `lua/core.lua`（`M.render` 的 sub 命令，L3311-3324） | 多推两个字段：`top`（视窗首行下标）、`viewport`（可见行数 N）、`total`（总行数） |
| 2 | `lua/main.lua` `drawSub`（L1122-1142） | 从 `top` 开始画 N 行（`i` 用 `top + k`），并在底部画「▲/▼ 还有 N 项」；说明行改由 `cmd.desc` 是否为空决定（见 §2） |
| 3 | `lua/main.lua` `subRowRect` / `subHitTest`（L356-367） | 行矩形加上 `top` 偏移（否则点击会错位） |
| 4 | 输入 | **不需要改**：`subMove` 已经能上下移动选中项；只要在 render 时让 `top` 跟随选中项（`top = clamp(sel - N + 1, 0, max(0, total - N))`） |
