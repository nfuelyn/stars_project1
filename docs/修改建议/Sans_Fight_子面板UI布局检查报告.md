## 2. 原因（纯几何，含具体数字）

面板几何：`核心 core.lua:3305-3324` 把子面板画在**当前战斗框内**（`pad = 8`）：

```
面板宽 pw = 框宽 - 16
行文字框 nameL = x + 28, nameW = pw - 120      ← main.lua:1135
备注框  noteR = x + pw - 20, noteW = 90（右对齐） ← main.lua:1137
```

| 回合结束时的框宽 | 面板宽 pw | **行名可用宽 = pw−120** | 备注框 | 两者重叠 |
|---|---|---|---|---|
| **165**（骨刺/终盘/螺旋 3 的框） | 149 | **29px** | 90px | **18px** |
| 237 | 221 | 101px | 90 | 18 |
| 305 | 289 | 169px | 90 | 18 |
| 405 / 575（多段等宽框） | 389 / 559 | 269 / 439px | 90 | 18 |

- 行名是**汉字**：18px 字号下 1 个字 ≈ 18px → **29px 只放得下 1.5 个字**；「传奇面包」需要 ≈72px、「检查」需要 ≈36px ⇒ 必然被压/截。
- 备注框（90px，右对齐到 `x+pw−20`）与行名框**硬重叠 18px**，且它的左边界 `x+pw−110` 已经**越过面板右边界**（pw=149 时 `x+39`，而面板右边界是 `x+149`？—— 实际是备注框整体被推到面板外：`x+pw−110 … x+pw−20` 在 pw=149 时 = `x+39 … x+129`，而**行名框是 `x+28 … x+57`**，两者交叠 18px；同时备注按 `x+pw−20 = x+129` 右对齐后**超出面板右下角**，截图里就是"文字挂在框外"）。
- 底部说明行宽只有 `pw − 28 = 121px`，而行动提示是 11~13 个字（≈176~208px）⇒ **必然被截**。
- 注：行**点击判定**用的是整行宽（`subRowRect`），所以点选不受影响，只是"看"不清。

## 3. 修改建议（按你的口径：**可以删掉行尾备注**）

### 方案 A（推荐，改动最小、最干净）

1. **删掉行尾备注**：让 `subRowNote()` 对 `act / item / mercy` 一律返回 `''`（或 `core.lua:3319-3323` 直接不传 `notes`）→ 右侧 90px 与那 18px 重叠带一起消失。
2. **行名占用整行**：`main.lua:1135` 的 `w - 120` → `w - 40`
   - 窄框 149 → 名字宽 **109px**（≈6 个汉字，够「传奇面包」72px、「检查」36px）
   - 宽框 404 → 364px
3. **说明行**：窄框时把字号压到 `min(16, floor((pw-28)/8))`，或超长时用 `utf8sub` 截断 + `…`（行动提示 11~13 字在 121px 里只能放 ~7 字）

改完的效果：行名完整、没有框外文字；代价是"结束回合/不结束回合/x20"这类辅助信息不再显示（可以在**底部说明行**里用一句话代替，例如「（此行动会结束回合）」）。

### 方案 B（保留备注）

- 把备注缩到极短（`结束`/`不结束`/`x20`）+ 行名框改成 `w−150`：**窄框仍然放不下**（149−150 < 0）⇒ 不可行；除非同时让备注字号 ≤10 并允许压到面板外。

### 方案 C（更彻底）

- 子面板**不再跟随战斗框**，固定用一个最小宽度（例如 420px 的浮层，与原版"菜单大框"一致）：`pw = math.max(boxAbs.w - 16, 420)`，并让面板在屏幕上居中。
- 好处：所有回合一致、与原版观感更接近；代价：改动面最大（面板位置/点击命中/触屏都要一起看）。
