# 「我方行动时把战斗框固定成长框」——方案评估（**未改代码**）

- **工作区**：`D:\stars\workspace\sans-fight`
- **日期**：2026-10-07
- **结论**：**可行，而且我推荐这么做** —— 这是修 ACT/ITEM 面板挤压问题**最干净**的办法（一次解决"名字被截、备注出框、说明被截、5 行物品排不下"四件事），副作用可控、且有 3 项现成的好处（见 §3）。

## 1. 建议固定成什么框

```
我方行动（menu / sub / attack）时的框 = x 33..608, y 226..391   （575 × 165）
                                        ↑ 与脚本自己的"长框"同宽（33..608）
                                        ↑ 高度取默认 165（不是脚本长框的 140，原因见 §2）
```

- **宽度 575**：和脚本 `:End` 用的长框一致（`CombatZoneResizeInstant,33,251,608,391`），面板可用宽 = 575−16 = **559**；
- **高度 165**：让 5 行物品也排得下（行区 = (165−16) − 58 = **91px**，5×18 = 90 ✓）；
  - 若照抄脚本长框的 **140** 高：行区只有 66px → 5 行物品**仍然溢出 24px**（必须减到 4 行/页或把行高压到 13px）→ 所以高度要 165。

## 2. 收益（正好覆盖上一份报告里的全部问题）

| 项 | 现状（框 165 宽时） | 固定长框后（575 宽 / 165 高） |
|---|---|---|
| 面板宽 pw | 149 | **559** |
| 行名可用宽 = pw−120 | **29px**（只放 1.5 个汉字 → 截图里「传…」「奶油…」） | **439px**（「传奇面包」72px、「检查」36px 绰绰有余） |
| 备注框（90px） | 与行名框重叠 18px，并被推到面板**外** | 仍有 18px 重叠带，但行名远用不满 → **视觉上不会撞** |
| 底部说明行宽 = pw−28 | 121px → 行动提示（11~13 字 ≈176~208px）**被截断** | **531px** → 完整显示 |
| 5 行物品行高 | rowH 18（高度够时）/ 矮框时溢出 | **rowH 18，恰好排下**（4 行→22、2 行→40） |

> 也就是说：**只改"我方行动时的框"，不改 `drawSub` 的任何字号/宽度**，上面四类问题一起消失。

## 4. 会带来的副作用（要一起处理）

1. **进入我方回合时框会横向撑开**（从上一回合的框 → 575 宽）。这是刻意的，且**每次一致**（不再"跟随上一回合忽宽忽窄"）✓；如果你希望有过渡，可以复用现成的 `CombatZoneResize/stepZone` 插值给菜单框做 0.15s 动画（额外工作量）。
2. **内置大框回合**（420×260，框顶 178.5）→ 菜单框顶 226 → **Sans 下移 47px、框顶下移**。若要完全避免，可把菜单框高度改成 `max(165, 上一回合框高)` —— 代价是"固定"变成了"半固定"。
3. **自测要同步**：`lua/core_selftest.lua:1004-1058` 的 `extra-box-bounds` 断言 ③「menu/sub/attack/result 的框 **y 与 enemy 相同**」在当前实现下成立；固定长框后菜单 y 变成 226（内置回合的 enemy y 是 178.5）→ **这条会 FAIL**，需要改成"允许我方行动期使用固定的长框（y 固定 226，且在屏内、居中）"。

## 5. 精确改动（待你点头后再落盘）

**`lua/core.lua`**：

```lua
-- (1) 在常量区加菜单框定义（放在 SCRIPT_BOX_W/H 附近）
local MENU_BOX = { x = 33, y = 226, w = 575, h = 165 }   -- 我方行动期的固定长框（33..608 × 226..391）

-- (2) 进入我方回合时用它（endEnemy 里，紧跟 self.state = 'menu' 之后）
function Game:endEnemy()
  ...
  self.state = 'menu'
  self.box = { x = MENU_BOX.x - BOX_OFF_X, y = MENU_BOX.y - BOX_OFF_Y, w = MENU_BOX.w, h = MENU_BOX.h }
  ...
end

-- (3) 开局初始框也用它（resetRun 里原来那个 420×260 的初始框）
  self.box = { x = MENU_BOX.x - BOX_OFF_X, y = MENU_BOX.y - BOX_OFF_Y, w = MENU_BOX.w, h = MENU_BOX.h }
```

**`lua/core_selftest.lua`**：把 `extra-box-bounds` 的第 ③ 条改成"我方行动期的框 = 固定长框（33..608 / 226..391，屏内 + 居中）"，并保留"敌人回合按各自 zone"的检查。

**不需要改**：`main.lua` 的 `drawSub`（行宽 120、行高下限 18 都刚好合适）、`attackBar`、菜单按钮布局、任何战斗脚本。
