## 1. 已确认的关键机制

| 项 | 原作行为 | 出处 |
|---|---|---|
| 战斗总长 | **23 回合以上；约 23 次攻击后通关** | 神ゲー「攻略ターン 23ターン以上※23回攻撃でクリア」 |
| 伤害 | 每次命中 **只扣 1 HP** | 检索片段（Wiki） |
| **无敌帧** | **没有无敌帧**（"ignore invincibility"）；装备「くもったメガネ」时才"能看到一点点效果" | 检索片段 + 神ゲー装备段 |
| KR（Karmic Retribution／因果报应） | 命中后留下**持续伤害**；**在指令菜单里也会继续掉血**；**一直掉到 HP=1 就停**（效果还在也不再往下掉） | 神ゲー「コマンド選択中も体力は減っていく」「HPが1になるまでは減り続けるが、1になると効果中でもそれ以上減らない」 |
| 恢复时机建议 | 等毒掉完再吃药；中场（第 12 次攻击后）是安全窗口 | 神ゲー |
| **中场（第 12 次攻击后）** | Sans **停手**，直到玩家主动攻击为止 → 这是官方给的**回血/上 buff 窗口** | 神ゲー「サンズはこちらから攻撃するまで行動しない」 |
| **中场选仁慈** | **立即死亡**（但下一次战斗台词会变） | 神ゲー「中間地点でサンズをみのがすと、即死してしまう」 |
| 回合 0 | 开局**先制偷袭**：不意打ち（立刻上跳）+ 骨の波 + 連続ビーム | 神ゲー |
| 回合 13 | 出现「ただひとつわかるのは…」台词后，**下一回合必定攻击** | 神ゲー |
| **后半菜单骨** | 后半第 1–3 回合**菜单里出现骨头**（碰到就掉血）；第 3 回合后变成菜单栏多根骨；第 6 回合后**菜单与血条上下同时出骨**（本轮仍未落实） | 神ゲー |
| 最终回合（スペシャル攻撃） | ① 高速重力 → リフト　② **横スクロール**（隙间穿越 ×1–2、第 3 个在中间高度等、最后不意打ち按左）　③ **骨 → 连続回転ビーム**（先大圈后小圈，**最后一击**） | 神ゲー |
| 壁ドン（撞墙） | 最终段有个"壁ドン"，**HP 不会因此变 0**（不致死） | 神ゲー「壁ドン HPは0にならないため放置」 |
| 收尾 | 撑过最终攻击后 Sans 用「特殊攻击」= **什么都不做、死不结束回合**；玩家只能等到他睡着，然后把战斗框往左下推到底按"战斗"才能击杀 | 萌娘百科 + 神ゲー |

## 2. 第一回合到第十二回合（前半）

| 回合 | 攻击 | 原作闪避要点 |
|---|---|---|
| 0 | 偷袭 | 立刻上跳；骨の波移到中间上下躲；连续光束 中→上→中→上 |
| 1 | 小跳反复 | 连续小跳钻骨缝，节奏与缝高固定 |
| 2 | **青骨 + 小骨** | **青骨时完全不动**，青骨过去瞬间最小跳 |
| 3 | 两侧骨头（骨くぐり） | 缝隙高度与速度随机，靠跳跃 |
| 4 | **足场渡り** | 平台出现即起跳 |
| 5 | 反向足场渡り + 骨 | 提前量要早 |
| 6 | 传送带 + 三段轨道 | 尽量落在最下层 |
| 7 | 小足场 + 隙间穿越 | 跳第一列 → 落右端静止 → 1-2 列间大跳 |
| 8 | **三段光束** | 尽量待下段；连续下段光束时改走中段 |
| 9 | 小足场（回合 7 的镜像） | 落左端 |
| 10 | 小跳（节奏加快） | 同回合 1 |
| 11 | キャタピラ（毛毛虫） | 中央等到最后一刻 → 向左大跳 → 保持右移 |
| 12 | 随机跳 | 同回合 3 |
| 13+ | 从 4 种里随机 | 直到累计 12 次攻击 |

## 3. 后半（11 回合）

| 回合 | 攻击 | 要点 |
|---|---|---|
| 1 | 4 种随机 ×5（随机跳／青骨／骨の波／サンドイッチ） | **除青骨外都立刻跳**；**菜单里开始出现骨头** |
| 2 | 细连续光束 | 边看下一条射线边移动；也可从细缝钻 |
| 3 | 5 种随机（骨の波／クロスビーム／十字ビーム／小足场／キャタピラ） | 对策各不同；结束后**菜单栏多根骨** |
| 4 | 低速重力叩きつけ | 被砸的方向**反向**按 |
| 5 | 中速重力 | 同上，节奏更快 |
| 6 | 太连续光束 | 射线更粗但间隔更长；结束后**菜单与血条同时出骨** |
| 7 | **リフト** | 反时针绕圈 |
| 8 | 随机（回合 1+3 的集合） | 瞬时判断 |
| 9 | 高速重力 | 反应要最快 |
| 10+ | 光束／高速重力／随机三选一 | 「次の攻撃のあとで発動するから」台词后**先吃全恢复** |
| 最终 | ① 高速重力→リフト ② 横スクロール ③ 骨→连続回転ビーム | 见上表 |
