## 一、Lua 文件分层

### A. 正式运行代码（千星脚本需要的部分）

| 文件 | 作用 | 千星侧是否需要单独建文件 |
|---|---|---|
| `lua/core.lua` | 纯战斗逻辑：回合、灵魂、KR、攻击命令、碰撞 | 否，内联进主脚本 |
| `lua/attacks.lua` | 27 个攻击 CSV 的数据层 | 否，内联进主脚本 |
| `lua/fitdata.lua` | Sans / 龙骨炮逐像素烘焙数据 | 否，内联进主脚本 |
| `lua/main.lua` | 千星适配层：创建控件、绑定输入、HUD、渲染 | 否，内联进主脚本 |
| `lua/boot.lua` | 本地模块入口；存档构建时会生成等价生命周期入口 | 否，仅本地参考 |

实际挂到千星的是一条**自足脚本**。`tools/build-save.mjs` 已把 `core + attacks + fitdata + main` 内联，并为千星生成 `OnInit / OnEnable / OnStart / OnUpdate / OnLevelUpdate / OnDisable / OnDestroy`。

### B. 不需要上传到千星的文件

- `lua/_check.lua`、`_rounds.lua`、`core_selftest.lua`、`_tap.lua`、`_title.lua`、`_input.lua`、`_geometry.lua`、`_pool.lua`、`_flow.lua`、`_adapter.lua`、`_box.lua`、`_sine.lua`、`_dbg.lua`
- `lua/_probe_*.lua` 与 `lua/probes/*.lua`
- `tools/*.mjs`、`tools/*.cjs`、`tools/*.py`
- `records/`、`reference/`、`docs/`、`prototype/`
- `reference/sprites/` 只有在改用自定义图片方案时才需要。

## 五、宿主 API 映射

`core.lua` 和 `attacks.lua` 不直接调用千星 API；只有 `main.lua` 需要宿主提供以下能力：

| Lua 调用 | 用途 |
|---|---|
| `game.GetClientUIControl(1)` | 取服务端根控件 |
| `game.GetUICanvasSize()` | 取当前画布宽高 |
| `game.GetDevice()` | 判断 PC / 触摸分支 |
| `game.InstantiateClientUIControl(guid, parent)` | 从模板池实例化控件 |
| `game.GetGlobalCustomVariableValue('Level', 'SansRound')` | 可选调试回合跳转 |
| `game.GetGlobalCustomVariableValue('Level', 'SansDifficulty')` | 可选调试难度 |
| 控件 `SetVisible` | 显示/隐藏 |
| 控件 `SetSizeDelta` / `SetAnchoredPosition` | 尺寸与位置 |
| 控件 `SetAnchorMin` / `SetAnchorMax` | 烘焙子块比例锚点 |
| 控件 `SetLocalRotation(0, 0, deg)` | 旋转骨骼、三角、光束 |
| 控件 `imageColor` | 图元着色 |
| 控件 `SetAsFirstSibling` / `SetAsLastSibling` | 背景与闪层 z 序 |
| 控件 `AddKeyEventListener` | 键盘语义事件 |
| 控件 `AddCursorEventListener` | 指针、触摸、拖拽 |
| `game.PlayAudio2D` | 可选音效；当前核心逻辑不依赖音频 |

## 六、输入映射

### PC

| 物理键 | 语义事件 |
|---|---|
| `W` / `↑` | `KeyboardMoveForwardKeyDown/Up` |
| `S` / `↓` | `KeyboardMoveBackwardKeyDown/Up` |
| `A` / `←` | `KeyboardMoveLeftKeyDown/Up` |
| `D` / `→` | `KeyboardMoveRightKeyDown/Up` |
| `Enter` / 小键盘回车 / `Space` / `Z` | `KeyboardMenuConfirmKeyDown/Up` |
| `J` | `KeyboardNormalAttackKeyDown/Up` |
| `Esc` / `X` | `KeyboardMenuBackKeyDown/Up` |

蓝魂跳跃键是确认键，不是单独的 `JumpKey`。

### 触摸

- 使用 `全屏光标区` 的 `CursorDown / CursorDrag / CursorUp / CursorClick`
- 左半屏拖动 = 摇杆
- 点按选项 = 第一次选中，第二次确认

## 十、结算按钮与退出奇域

结局页新增按钮：

- 左：`结 算`
- 右：`重 开`

确认 `结 算` 后，客户端发送：

```lua
local sig = game.ServerSignal('SansFightSettle')
sig:AddString('result', 'victory')
sig:AddInt('hp', hp)
sig:AddInt('kr', kr)
sig:AddInt('round', round)
sig:SendSignal()
```

真实千星侧需要增加一个服务端节点图：接收 `SansFightSettle`，执行“胜利结算”和“退出奇域/结束关卡”。

模拟器没有真实退出奇域运行时，因此本地只验证按钮、`胜 利 结 算`页面和信号发送。详细节点图与挂载见 `docs/结算按钮_节点图与挂载映射.md`。
