# 千星沙箱映射清单（审判者战 · sans-fight）

> **一句话**：编辑器里只需要建 **1 个客户端控件组（10 个模板）** + **1 个服务端控件组（2 个节点）** + **挂 1 条脚本**。
> 所有战斗画面（框 / 骨头 / Sans / 龙骨炮 / HUD / 心）都是**运行期** `InstantiateClientUIControl(guid, parent)` 实例化出来的，
> **编辑器里一个控件都不用摆**。
>
> 权威来源：`tools/build-save.mjs` 的 `TEMPLATES`（生成存档）与 `tools/verify-client-pool.mjs`（10 项契约校验）。

---

### 三条硬要求

1. **GUID 不能改** —— Lua 侧就是按这些 guid 实例化的，错一个 → 那一类图元整块消失（日志会打 `inst NIL`）。
2. **锚点/pivot 不能随便选**：
   - 1~4 必须**左下角**（画布坐标 = 直接是左下的位置参数）
   - 5、6 必须**中心**（旋转要绕自身中心；用左下角会绕角转、画面全歪）
   - 7、10 必须**拉伸铺满父容器**
3. **不要在编辑器里摆实例** —— 池是运行期 `OnStart` 预建的（`main.lua` 的 `BUDGET`），这 10 个只是「被实例化的模板」。

## 二、服务端控件组：2 个节点

| 节点 | GUID | 名字 | 作用 |
| --- | --- | --- | --- |
| 根 | `1073741850` | 客户端控件容器 | 客户端资产挂载点 |
| 挂载容器 | `1073741851` | 容器节点 | **挂脚本**（`scriptMappingIds=[1073742105]`）+ **必须打开 `showCursor`** |

> `showCursor` 是**指针 / 触摸事件的前提**（`worker.js` 的 `cursorEventsEnabled` 判定祖先容器），忘了会出现「画面正常但完全点不动」。

## 四、**不需要**做的事

- 不需要在编辑器里摆战斗框、骨头、Sans、龙骨炮、HUD、心 —— **全部运行期实例化**
- 不需要给服务端节点加除 `showCursor` 以外的任何 UI 属性
- 不需要准备字体 / 贴图 —— 图元用引擎内置（100001 矩 / 100002 圆 / 100003 三角 / 100006 环），字体用默认
- 不需要手动摆「层级顺序」—— 闪层/背景/烘焙层在运行期用 `SetAsFirstSibling/SetAsLastSibling` 钉好

## 五、自检：怎么确认映射对了

1. 导入存档 → 试玩 → 看**启动日志**：

   ```
   main start: build=2026-10-06-bluesoul device=… touch=… mode=core pool=2018 flash=true cursor=true
   ```

   | 字段 | 期望 | 不对说明 |
   | --- | --- | --- |
   | `pool=2018` | 预建控件总数（BUDGET 求和 + 背景 + 闪层 + 烘焙根） | 数字偏小 → 某个模板没建起来 |
   | `flash=true` | 全屏闪层创建成功 | false → 矩形图元缺失 |
   | `cursor=true` | 光标区创建成功 | false → 光标区模板缺失 |

2. 若日志出现 `main: 客户端模板缺失 —— 图元「x」索引 N 实例化失败` → **照 N 去补那个 GUID**。
3. 离线契约校验：`node tools/verify-client-pool.mjs` → 应打印 **PASS（10 项契约全部满足）**。
4. 目视：开局应有**纯黑底** + **白色战斗框** + **红心** + 底部 HUD（LV / HP / 血条 / KR / ROUND / 难度）。

## 六、以后若要上「1 张龙骨炮图片」方案（性能 ≈1/24）

需要在千星里**额外注册自定义图片**（现在项目只用内置图元）：

| 项 | 内容 |
| --- | --- |
| 素材 | `reference/sprites/fit/blaster_Default.png` + `blaster_Fire_000~004.png`（每张是 3 连雪碧图，取 374×264 一格） |
| 数量 | 先 1 张（只求性能）或 5 张（保留开火动画） |
| 注册后 | 每个拿到一个 `imageId`（例如 100101~100105），代码里 `c.imageId = …` 即可 |
| ⚠️ 前提 | **沙箱是否支持存档携带自定义图**尚未验证 —— 需先做 10 分钟实验（放一张 8×8 纯色图看能否显示） |

现状对比（终盘阶段④ 9 发同屏）：现在 **1161 个控件 / 3574 次写/帧**；1 张图方案 → **36 个控件 / ~150 次写**。

## 七、常见坑（都踩过）

| 现象 | 原因 |
| --- | --- |
| 整类图元不显示，日志 `inst NIL` | 对应的 GUID 没建 / 写错 |
| 画面全歪、旋转件围着角转 | 旋转图元用了左下角锚点而不是中心 |
| 只能点到一小块区域 | 全屏光标区没设「拉伸铺满」 |
| 画面正常但点/拖没反应 | 服务端祖先容器没开 `showCursor` |
| 闪白时能看见弹幕浮在白层上面 | 控件池不足 → 运行期新实例排在闪层之后（池已在 OnStart 预热，别把 BUDGET 调小） |
| 文本全挤在左边 | 文本图元的 `horizontalAlignment` 只认 `Left/Middle/Right`（写小写无效） |
