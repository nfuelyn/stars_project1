# 结算按钮：退出奇域 / 胜利结算 —— 节点图与挂载映射

- 工作区：`D:\stars\workspace\sans-fight`
- 当前构建：`2026-10-07-krframe`
- 结论：客户端 Lua **不直接调用退出奇域 API**；结算按钮发送服务端信号 `SansFightSettle`，由千星节点图负责“胜利结算 + 退出奇域”。

---

## 一、客户端行为

结局页面现在有两个按钮，布局为：

```text
[ 结 算 ]   [ 重 开 ]
```

- `结 算` 在左，默认选中 `重 开`
- `←/A` `→/D` 切换
- `Enter / 空格 / Z / J` 执行当前按钮
- 触屏：第一次点选，第二次确认

点击 `结 算` 后：

1. Lua 将结果页标题切为 `胜 利 结 算`
2. 设置 `state.settleRequested = true`
3. `main.lua` 发送服务端信号：

```lua
local sig = game.ServerSignal('SansFightSettle')
sig:AddString('result', 'victory')
sig:AddInt('hp', hp)
sig:AddInt('kr', kr)
sig:AddInt('round', round)
sig:SendSignal()
```

信号参数：

| 参数 | 类型 | 意义 |
|---|---|---|
| `result` | String | 固定为 `victory` |
| `hp` | Int | 结算时 HP |
| `kr` | Int | 结算时 KR |
| `round` | Int | 当前 HUD 回合，1–24 |

## 二、千星服务端节点图

节点名可能因编辑器版本不同而略有差异；按功能对应即可。

```text
[客户端 Lua：结算按钮]
        |
        | game.ServerSignal("SansFightSettle")
        v
[服务端：收到服务器信号 SansFightSettle]
        |
        +--> [可选] 设置 Level 自定义变量
        |       Level.SansFightResult = String("victory")
        |       Level.SansFightHP     = Int(hp)
        |       Level.SansFightKR     = Int(kr)
        |
        +--> [胜利结算 / 通关结算]
        |
        +--> [退出奇域 / 结束关卡]
```

### 节点对应关系

| 节点 | 输入 | 输出 / 动作 |
|---|---|---|
| 服务器信号接收 | 信号名 `SansFightSettle` | 取得 `result / hp / kr / round` |
| 自定义变量设置（可选） | 上述参数 | 写入 `Level.SansFightResult` 等 |
| 胜利结算 | 结算结果 = 胜利 | 显示“胜利”/完成结算 |
| 退出奇域 | 结算完成 | 退出当前奇域或等价结束节点 |

如果编辑器里没有“退出奇域”节点，使用以下任一等价替代：

- `结束关卡`
- `退出试玩`
- `返回大厅`
- `显示结算面板`
- `结算并返回`

客户端仍然会显示“胜 利 结 算”；退出动作由服务端节点图决定。

## 四、当前能不能直接退出奇域

当前模拟器：

- `game.ServerSignal` 可以发送，模拟器会记录为 inbound server signal
- 模拟器没有真实“退出奇域”运行时 API
- 因此本地试玩点击 `结 算` 后：
  - 会显示 `胜 利 结 算`
  - 会发送 `SansFightSettle`
  - 不会真的退出模拟器

真实千星：

- 需要在编辑器中按上面的节点图接入服务端信号
- `SansFightSettle` 收到后，使用官方的“胜利/结算/退出奇域/结束关卡”节点完成退出
- 若没有退出节点，则退化为“显示胜利结算面板”
