## 1. 玩家与幻想

- 目标玩家：玩过或听说过 Undertale、想体验"审判长廊里被弹幕支配"的紧张感；熟练度中等，单局 3–5 分钟（20 回合 + 结算）。
- 一句话幻想：**玩家在一个方形战斗框里操控一颗红心，通过躲开骨头与冲击波，在 20 回合审判中活到最后，获得"我撑过来了"的成就感。**
- 题材与边界：纯 2D、纯客户端控件 + Lua 驱动（无节点图、无 3D、无联网）。对手 Sans 以几何占位图形 + 文本标签表现。

## 2. 体验支柱

| HYPOTHESIS | 玩家可感知表现 | 反例 | 验证方式 |

## 3. P0 核心循环

- **唯一核心动词**：移动灵魂（红心）以躲开弹幕。
- 输入：
  - PC：`WASD` / 方向键移动；`空格`或`回车`确认；菜单用方向键 + 确认。
  - 手机：在战斗框内**拖动**灵魂（手指相对位移，1:1）；菜单点按；蓝魂模式点按/上滑跳跃。
- 状态机：

```
boot → ready → player_turn(menu) ⇄ enemy_turn(pattern) → resolved(win|fail) → restart
```

- 开局看到什么：黑底、中央一个方形战斗框、框内一颗红心、上方 Sans 与台词、下方 4 个菜单按钮（攻击/行动/道具/仁慈）、左上 HP 20/20 与 KR 0。
- 第一次有效操作：在 Sans 的第一波骨头里横移躲开 → 不掉血 → 回合结束。
- 成功：撑过 20 个 Sans 回合后，在**最后一回合**选择 **攻击**（击倒）或 **仁慈**（饶恕）→ 两个结局文案。
- 失败：HP 归零 → GAME OVER 画面 + 重开。
- 最短上手路径：`开局 → 第一次躲开 → 第一次受伤（KR 开始跳） → 撑到回合 2 → 重开`。

目标循环：`看到预警 → 移动 → 即时反馈（闪避/受伤红闪+KR跳动） → 局势变化（HP/KR/回合数） → 成功或失败 → 重开`。

## 4. 玩法契约（CONTRACT，可自动化断言）

| ID | 规则 | Oracle（可观察） |

| C1 生命 | 最大 HP = 20；每次被弹幕命中 **-1 HP**，命中后 0.8s 无敌 | 命中前后 HP 差值 = 1；0.8s 内连续命中不叠加 |

> **v5 原作复刻研究（用户指定参考 jcw87 的 Bad Time Simulator）**：见 `docs/bts-study.md`。
> 该工程把 Sans 战做成**数据驱动的 CSV 攻击脚本**（每行 `延时, 命令, 参数…`，配标签 / JMP / 数学 / RND）。
> 由此得到的校准与采纳：
> 1. **颜色语义对齐原作**：`Color 0=白 / 1=蓝 / 2=橙` → 我们补上**橙骨（必须移动）**，蓝/橙交替 + 颜色图例。
> 2. **速度换算**：原作数值是"30fps 的 px/帧"，**等效 px/s = 原作值 × 30**；据此把「原作」档速度从 1.00 提到 1.25（进一步逼近留给专项调参）。
> 3. **`BoneStab` 的 `WarnTime`** 就是"冒头预示"的官方实现（原作仅 0.1667s，我们用 0.5s 更友好）——我们的 `peek` 阶段与它语义一致，命名对齐。
> 4. **架构采纳（步骤 5）**：Lua 侧把回合流程改成**表驱动**（`{t, cmd, args}` 列表 + 跳转），而不是写死状态机。
> 5. 待做清单：蓝骨**配对白骨**、战斗框**连续变形**（`CombatZoneResize`）、`HeartTeleport`、真正的**砸击**（`SansSlam` + 可关伤害的"壁ドン"）；龙骨炮的**旋转蓄力段**（`SpinTime`）已于本轮落实（见上「20 回合结构」的螺旋三档）。

| `行动` | `* 行动` 四行清单 + 底部说明 | 检查 / 挑衅 / 求饶 / 沉默 | 检查=看数据；挑衅=之后每回合快 10%（`act_taunt`）；求饶=清空 KR（`kr_cleared`）；**沉默不结束回合** |
| `道具` | `* 道具` 清单（名称 + x数量 + 说明） | 雪镇薯条 x1（+8）/ 热猫 x1（+12） | 用完即 `item_used`；空背包 `item_empty` |
| `仁慈` | `* 仁慈` 两行 + 说明 | 饶恕 / 逃跑 | 最终回合饶恕 → 饶恕结局；否则 `mercy_refused` / `flee_refused` |

子面板操作：`↑↓`（或 `W/S`）选择、`回车/空格` 确认、`Esc` 返回菜单（`sub_back`）；触屏点行选择、点面板外返回。

**中场（原作第 12 次攻击后的官方补给窗口）**：内部号 11（HUD 显示 ROUND 12 / 20）结束后 Sans **停手**，直到玩家主动「攻击」为止。中场内可反复用道具 / 行动回血，**回合不推进**；此阶段选「仁慈」= **立即死亡**（原作：みのがすと即死），日志 `fail spared_midpoint`。

## 7. 体验与约束

- 可访问性：所有危险状态都有**颜色之外的反馈**（KR 用文字数字 + 条，蓝骨用青色 + "不要动"提示文本）；不依赖音频；不闪烁超过 3Hz（受伤红闪为单次 0.12s）。
- 画布：整屏构图以 **`mobile-16-9`（1280×720）完整可见**为基准；PC 用同一设计板 `min(canvas/design)` 等比放大、不足处留边，**禁止按 PC 铺满后裁手机**。
- 触控热区：菜单按钮高 ≥ 64px；战斗框拖动区 = 整个战斗框（避免手指遮挡中心，命中偏移按手指相对位移而非绝对位置）。
- 美术意图：全部为**几何占位**（圆/矩形/多边形自绘 + 图元 `100001–100006`）；参考图只用于对齐"辨识度"，不复制版权形象。
- 权利假设：不使用 Undertale 的任何图像、音频、字体、文本；名字在本作内不使用原作角色名，改用原创代号（如「审判者」），对外描述也只说"弹幕回合制躲避"。

## 8. 客户端控件与模板方案（技术契约）

游戏由 **11 类客户端控件 + Lua 实例化客户端模板**构成；服务端「客户端控件容器」只是资源分组，**不能挂脚本**，脚本一律挂客户端控件。

| 用途 | 控件/模板 | 说明 |
|---|---|---|
| 舞台 | 容器 `Stage`（1280×720 设计板） | 等比缩放容器，**不再叠全屏不透明兄弟节点** |
| 战斗框 | 容器 `Box` | 尺寸按回合切换（C5） |
| HUD | 进度条 `HUD_HP`、`HUD_KR` + 文本框 `HUD_HPText`、`HUD_KRText`、`HUD_Round` | `fillAmount` 0–1 |
| 台词 | 文本框 `SansLine` | 逐字显示 |
| 菜单 | 预设按钮 `Menu_Attack` / `Menu_Act` / `Menu_Item` / `Menu_Mercy` + 各自文本框 | 按钮四状态用官方预设 |
| 输入 | 光标检测区域 `Box`（拖动） + 按键提示 `KeyHint` | PC/手机同一套逻辑 |
| 弹幕实体 | **客户端控件模板** `Tpl_Bone_White`、`Tpl_Bone_Blue`、`Tpl_Blaster`、`Tpl_Platform`、`Tpl_Soul`、`Tpl_HitText` | 模板实例化 + **对象池**（预实例化、`SetVisible` 复用） |
| 反馈 | 全屏动效 `Flash`、界面动效 `HitFx` | 受伤红闪（P0 单次）、命中特效（P1） |
| 结算 | 容器 `ResultPanel` + 文本框 + 按钮 `Btn_Restart` | 胜利/失败共用 |
| P1 | 网格视窗 `Grid_Items` | 道具列表 |

**对象池协议**：每个模板预实例化 N 个（白骨 24、蓝骨 8、冲击波 4、平台 3、飘字 8），运行时只改位置/可见性，不频繁创建销毁。

**Sans 本体与龙骨炮的渲染契约（进行中，只定契约与尺寸依据）**：core 每帧输出 `kind = 'sans'` 渲染命令（世界坐标 640×480，Y 向下），字段为 `x`（站位中心，默认 320）、`y`（**头顶** y，常量 `SANS_HEAD_TOP = 326`，脚底落在 474）、`head`（Default / ClosedEyes / BlueEye / NoEyes / Tired1 / Tired2）、`body`（nil / HandRight / HandDown / HandLeft / HandUp）、`torso`、`anim`、`sweat`（0..3）、`dodge`（0..1）、`alpha`。
尺寸依据照原作：头 32×30、躯干 54×25、身体 64×70、腿 44×23、汗滴 32×9（合计 148 高）；框下沿 391、屏幕底 480，所以他的**头会探进框里** —— 这是原版构图。
适配层（`lua/main.lua`）正按这个契约用图元拼装 sans 与龙骨炮（原作炮身 **57×44** 的骷髅炮：颅骨 + 长吻 + 两个黑眼窝 + 獠牙）。

## 10. HTML 效果展示（步骤 3，不碰模拟器）

- 必须可玩的场景：`boot`（标题→开始）/ `first-success`（躲过第一波骨头）/ `first-fail`（HP 归零）/ `restart`（重开复位）。
- 分级标注：`must-reproduce` = 灵魂移动手感、骨头/冲击波预警、KR 掉血与 1 HP 下限、回合切换节奏、菜单可用性；`can-degrade` = 命中特效、Sans 表情；`concept-only` = 音效、最终结局演出。
- 坐标差异：千星原点**左下、Y 向上**；HTML 左上、Y 向下。原型内所有坐标在 `toQxqyY()` 一处换算，**禁止把 HTML 像素直接搬进 Lua**。
