# prototype/ —— 步骤 3 HTML 效果展示

**这是体验展示，不是交付物，也不是 Lua 源码或千星证据。**证据等级 `runtime=html`。

## 怎么打开

直接双击 `index.html`（`file://` 可运行，无需服务器）。或：

```sh
# 可选：起个静态服务（手机同局域网测试更方便）
npx --yes serve .
```

## 怎么玩

| 操作 | 键盘 | 触屏/鼠标 |
|---|---|---|
| 移动灵魂 | `WASD` / 方向键 | 在战斗框内**拖动**（按相对位移，手指不遮住灵魂） |
| 确认 | `空格` / `回车` | 点按钮 / 点画面 |
| 菜单选择 | `1`–`4` 或左右键 + 确认 | 点四个菜单按钮 |

| 日志 | `L` | —— |
| 重开 | `R` | 点「重开」 |

## 覆盖到的四个场景

- `boot`：标题 → 点击开始 → HP 20/20、KR 0、第 1 回合
- `first-success`：第 1 回合第 1 波骨头**出生点必留安全位**，站着不动也能无伤通过（上手保证）
- `first-fail`：被骨头/冲击波直接命中扣到 0 → GAME OVER
- `restart`：结算界面点重开 → HP/KR/回合全部复位

## 测试入口（URL 参数，对应千星侧服务端变量）

| URL 参数 | 对应千星变量 | 作用 |
|---|---|---|
| `?seed=1` | `TestSeed` | 固定弹幕随机序列（C10 确定性） |
| `?hp=2` | `TestHP` | 覆盖初始 HP |
| `?round=3` | `TestStartRound` | 直接跳到某个回合 |
| `?nospawn=1` | `TestNoSpawn` | 不生成弹幕（隔离 KR / 生命规则） |
| `?hits=1.0,3.0` | `TestHitsAt` | 在指定秒数强制命中（走同一条伤害路径） |
| `?aim=1` | `TestAimWave1` | 第 1 波不留出生点安全位（反例） |

例：`index.html?hp=2&nospawn=1&hits=1.0` 复现「KR 不致死」。

## 不可移植项（HTML → 千星时必须重做，不能照搬）

- **坐标**：这里原点左上、Y 向下；千星原点**左下、Y 向上**。换算只在 `game.js` 的 `qxqyY()` 一处，**禁止把本文件的像素直接搬进 Lua**。
- **DOM/CSS 缩放**：这里用 `canvas.style.width` 等比留边；千星侧要用「固定设计尺寸的板 + `min(canvas/design)` 缩放容器」，且**缩放容器上不要再叠全屏不透明兄弟节点**。
- **绘制方式**：这里是 canvas 自绘；千星侧必须换成**控件**（图片/文本框/进度条/预设按钮）与**客户端模板实例化**，骨头与冲击波走对象池复用。
- 分级：`must-reproduce` = 灵魂移动手感、预警、KR 掉血与 1 HP 下限、回合节奏、菜单可用性；`can-degrade` = 命中特效、Sans 表情；`concept-only` = 音效、结局演出。
