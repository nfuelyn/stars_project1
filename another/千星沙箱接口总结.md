## 1. 项目如何使用千星沙箱

战斗运行在千星客户端的 2D 画布内：**Lua 负责逻辑**（HP/KR、心形玩家、攻击时间线、菜单、音效、结算），**客户端控件负责显示**（用纯色图元拼出 Sans、骨头、龙骨炮、文字、界面）。

平台接口的调用集中在适配层 `lua/main.lua`，核心层 `lua/core.lua` 不直接依赖平台接口，因此可以离线测试、再接入画面。架构分工：

```text
键盘/手柄/指针  →  客户端适配 lua/main.lua  →  战斗核心 lua/core.lua
                        ↑                          ↓
                 CodeArt 配方/字形          渲染命令列表
                        ↑                          ↓
                     千星控件树  ←  适配层绘制  ←  —
                        ↓
                音频模块 → game.PlayAudio2D
                结算发送 → game.ServerSignal / AddXxx / SendSignal
```

两个窗口的分工（`docs/部署与设置.md` 第 1 节）：

| 窗口 | 本项目要做的事 |
| --- | --- |
| 原神内的局内编辑器（游戏窗口） | 单人关卡、出生点、界面布局、客户端控件容器、客户端模板、脚本挂载、结算显示设置 |
| 千星沙箱窗口 | 建立 `main.lua` 脚本映射；声明服务器结算信号；连服务器节点图；看客户端脚本日志与调试 |
| 工作目录 | 改配置、构建 `main.lua`、离线测试 |

> 官方规定：客户端控件容器必须处于**激活且可见**状态，客户端控件与脚本才正常工作；关容器、传送、重连可能重建客户端控件。（`docs/部署与设置.md`）

## 2. 脚本生命周期与挂载接口

### 2.1 脚本映射与宿主

- 在**客户端脚本资源管理器 → 客户端脚本映射文件夹**中新建脚本映射 `SansFight`，关联工作目录的 `main.lua`。
- 在游戏窗口把该映射**只挂在根容器节点一次**（`SansFightRoot`），不要给其它控件重复挂载。
- 脚本宿主对象：`script.object` —— 就是脚本挂载的根容器节点，适配层把它当作 `root`（`lua/main.lua` `M.OnInit`）。
- `script:EnableUpdate(true)` —— 开启脚本的帧更新。

映射命中后，日志应出现 `main start: build=... device=... touch=... mode=core ...`，用于确认真机跑的是最新代码。

### 2.2 生命周期回调（适配层导出）

| 回调 | 作用 | 备注 |
| --- | --- | --- |
| `M.OnInit()` | 取宿主 `root`、读画布尺寸做 `layout()` | 真机优先 `script.object`，回退 `game.GetClientUIControl`（见 §3.3） |
| `M.OnStart()` | 初始化一次性资源：背景板、烘焙根、图层、控件池、光标区、核心/音频、注册输入 | 用 `M.runtime.started` 防重入 |
| `M.OnUpdate(dt)` | 仅当 `C.updateCallback == 'ui'` 时转发到 `OnLevelUpdate(dt, true)` | 默认不推进，避免双推进 |
| `M.OnLevelUpdate(dt, fromUI)` | 主更新：读输入 → 固定步推进核心 → 绘制 | 默认真机回调，与关卡暂停一致 |
| `M.OnDisable()` | 停音效、清输入、置 `enabled=false` | |
| `M.OnEnable()` | 恢复 `enabled=true`，已启动则清输入 | |
| `M.OnDestroy()` | 卸载按键监听、清光标监听、销毁自建控件、清缓存 | 不销毁宿主 root |

**关键事实**：官方同时提供 `OnUpdate` 与 `OnLevelUpdate`，**不能两个都推进**战斗。默认配置 `C.updateCallback='level'` 使用 `OnLevelUpdate`；只有确认外部宿主仅调用 `OnUpdate` 时才改成 `'ui'`。（`docs/部署与设置.md` 第 4 节）

## 3. 客户端控件 API

适配层通过这些全局接口创建、查询、销毁控件，并用控件方法与属性驱动画面。

### 3.1 全局函数

| 接口 | 签名 / 用法（源码中实际调用） | 说明 |
| --- | --- | --- |
| `game.InstantiateClientUIControl(prefab, parent)` | 由**控件模板索引**实例化控件，挂到 `parent` 下 | 适配层 `instantiateTemplate`，模板索引来自 `C.templates` / `G_REAL` |
| `game.GetClientUIControl(id)` | 按运行时 **id** 取控件 | 仅作宿主 root 的回退查找（`{1073741857, 1073741856, 1}`） |
| `game.DestroyClientUIControl(c)` | 销毁控件 | `OnDestroy` 中遍历 `M.runtime.ownedControls` 回收，**不销毁宿主 root** |
| `game.GetUICanvasSize()` | 返回画布宽高 `CW, CH` | `layout()` 用它算缩放与居中 |

### 3.2 常用控件方法

| 方法 | 参数 | 用途 |
| --- | --- | --- |
| `SetActive(bool)` | 激活状态 | 实例化后**父层与叶子都要激活** |
| `SetVisible(bool)` | 可见状态 | 控件池显隐 |
| `SetSizeDelta(w, h)` | 尺寸增量 | 定义矩形/容器大小 |
| `SetAnchoredPosition(x, y)` | 锚点位置 | 摆放控件 |
| `SetAnchorMin(x, y)` / `SetAnchorMax(x, y)` | 归一化锚点 | 烘焙矩形用比例锚点，缩放父容器即可整体缩放 |
| `SetPivot(x, y)` | 轴心 | 居中件用 `0.5`，其余 `0` |
| `SetLocalRotation(x, y, z)` | **三个参数** | 2D 旋转在 **Z 轴**；只传一个角度会写到 X 轴导致"从不旋转" |
| `SetAsFirstSibling()` / `SetAsLastSibling()` | 无 | 显式层序：黑底钉最底、闪层钉最上 |
| `GetChildren()` | 返回子控件表 | 识别包装模板里的叶子控件 |
| `GetChild(i)` | 第 i 个子控件 | 旧编辑器包装模板回退 |
| `SetImage(source, imageId)` | `Enum.ImageSource.StaticReference, id` | 运行时替换图片资产；`images=0` 时不调用 |

### 3.3 控件属性（可直接赋值）

| 属性 | 类型要求 | 用途 |
| --- | --- | --- |
| `imageColor` | **官方 ColorValue**（经 `Color(r,g,b,a)` 转换） | 图片控件染色，整数 `0xAARRGGBB` 不能直接写 |
| `fontColor` | ColorValue | 文本颜色 |
| `bgColor` | ColorValue | 文本背景（本项目设为透明 `0x00000000`） |
| `text` | 字符串（UTF-8 安全截断） | 文本控件内容 |
| `fontSize` | **整数**（写小数会抛异常） | 字号；适配层 `math.floor(fs+0.5)` 并保证 `≥1` |
| `horizontalAlignment` | `Enum.TextHorizontalAlignment` 枚举项 | 对齐方式 |
| `raycastTarget` | 布尔，**仅光标控件** | 光标检测区启用；未文档化地写到普通图片上会被拒 |
| `showCursor`（root） | 布尔 | 显示常驻光标 |
| `disableKeyEventPassthrough`（root） | 布尔 | 屏蔽按键事件穿透 |
| `disableCursorEventPassthrough`（root） | 布尔 | 屏蔽区域内光标事件穿透 |

### 3.4 控件模板（prefab）概念

- **模板索引**（`C.templates` 中的数字）是"客户端控件模板"的根节点索引，用于 `game.InstantiateClientUIControl`；**不是**运行时控件 id，也不是图片资产 ID。
- 模板索引是**每个工程各自的值**，不能跨工程照抄。当前工程用 `1073741855`–`1073741862` 一组（`lua/config.lua`）。
- 模板可以是叶子控件，也可以是"容器 + 一个叶子"的包装；适配层 `unwrapTemplate` 递归 `GetChildren()` 找到正确叶子，并把包装层拉伸归一化。
- 本项目需要的 8 类模板（`docs/部署与设置.md` 第 3 节）：

| 配置键 | 推荐内容 | 说明 |
| --- | --- | --- |
| `rect` | 纯白实心矩形（图片控件） | 可拉伸到 1px 到全屏 |
| `rot` | 实心矩形 | 旋转由代码控制 |
| `circle` | 纯白实心圆 | 骨头端帽 |
| `rtri` | 纯白三角形 | 其它三角图元 |
| `ring` | 纯白圆环 | 触摸摇杆 |
| `text` | 文本框控件 | 透明底、白字，作为兼容回退 |
| `cursor` | 光标检测区域控件 | 接收指针事件 |
| `baked/bakedC/bakedRoot` | 空容器节点控件 | 三个键可共用同一索引 |

> 注意：`images=0` 表示**沿用模板内的图片**（不是透明）；`audio=0` 才表示静音。

## 4. 枚举与数据类型接口

| 名称 | 用法 | 说明 |
| --- | --- | --- |
| `Enum[group][name]` | `M.enumValue(group, name)` 安全取值 | 取不到返回 `nil` |
| `EnumItem` | 键事件 / 光标事件 / 对齐 / 设备等均为枚举项 | 事件必须是 EnumItem，**不是字符串** |
| `Color(r, g, b, a)` | 生成官方 ColorValue | 整数需先拆分为 RGBA 分量 |
| `Enum.KeyEventType` | 按键事件类型（含 `...Down` / `...Up`） | 见 §5.1 |
| `Enum.CursorEventType` | `CursorDown` / `CursorDrag` / `CursorUp` / `CursorClick` | 见 §5.2 |
| `Enum.ImageSource` | `StaticReference` | `SetImage` 第一参数 |
| `Enum.Device` | `KeyboardAndMouse` / `Mobile` / `Controller` / `MobileController` | 见 §5.3 |
| `Enum.CustomVariableEntityType` | `Level` | 读关卡全局自定义变量 |
| `Enum.TextHorizontalAlignment` | 文本对齐 | 写 `horizontalAlignment` |

**类型坑（来自 `docs/项目交接与开发说明.md` §9）**：
- 控件身份字段是**小写 `id`**；不要把模板索引当运行时 id。
- `imageColor/fontColor/bgColor` 必须是官方 ColorValue，不能把整数原样写进去。
- `SetLocalRotation` 是**三个参数**，2D 旋转在 Z 轴。
- 键事件、对齐都用 EnumItem；`fontSize` 是整数。

## 5. 输入接口

### 5.1 键盘（按键事件）

- 注册：`root:AddKeyEventListener(event, callback)`，`event = Enum.KeyEventType[name]`
- 卸载：`root:RemoveKeyEventListener(event, callback)` —— **必须保存同一个回调对象**，否则卸载不掉。
- 事件名成对出现：`<键名>Down` / `<键名>Up`（源码用 `bind(n .. 'Down', ...)` 生成）。

源码中实际使用的语义键名（`lua/main.lua` `bindKeys` / `bindAction`）：

| 逻辑动作 | 键名 |
| --- | --- |
| 上 | `KeyboardMoveForwardKey`、`KeyboardCraftspersonKey36`、`ControllerCharacterSkill3Key` |
| 下 | `KeyboardMoveBackwardKey`、`KeyboardCraftspersonKey37`、`ControllerCraftspersonKey2` |
| 左 | `KeyboardMoveLeftKey`、`KeyboardCraftspersonKey38`、`ControllerCraftspersonKey1` |
| 右 | `KeyboardMoveRightKey`、`KeyboardCraftspersonKey39`、`ControllerCharacterSkill4Key` |
| 确认 | `KeyboardCraftspersonKey12`、`KeyboardCraftspersonKey19`、`KeyboardJumpKey`、`ControllerJumpKey`、`ControllerMenuConfirmKey`、`KeyboardMenuConfirmKey` |
| 返回/慢走 | `KeyboardDropKey`、`KeyboardCraftspersonKey42`、`ControllerNormalAttackKey`、`ControllerMenuBackKey`、`KeyboardMenuBackKey` |

实现细节：
- 每个**物理按键**单独记录 held 状态，再合并方向位（松开 W 不会取消仍按着的上箭头）。
- 方向键与 WASD 分别注册；按住状态按实际按键合并。
- `MenuConfirm` / `MenuBack` 属于**可选别名**，官方不存在时跳过；`Enter/Esc` 不承诺为官方确认/返回键。
- 按键到达日志：首次收到会打印一行，用于区分"事件没到 Lua"与"逻辑没响应"。

### 5.2 指针 / 触摸（光标事件）

- 注册：`cursorArea:AddCursorEventListener(event, callback)`，`event = Enum.CursorEventType[...]`
- 清空：`cursorArea:RemoveAllCursorEventListeners()`
- 事件对象字段/方法：
  - `e.x`, `e.y`（拿不到时回退 `e:GetUIPos()`）
  - `e.touchId` —— 多点触控归属判断，第二触点不能夺走或提前结束摇杆
- 事件语义（`lua/main.lua` `bindPointer`）：
  - `CursorDown`：记录按下点、是否触摸；触摸分支左半屏在敌方阶段起浮动摇杆（菜单/面板/攻击条优先，不吞 UI 点击）
  - `CursorDrag`：更新摇杆偏移；拖动超过阈值标记 `moved`
  - `CursorUp`：松手；`moved` 为假才算"点按"
  - `CursorClick`：与 `CursorUp` 的同一一点按去重，避免一次点击走两次确认
- 光标检测区必须是 `cursor` 模板并设 `raycastTarget=true`；`root.showCursor=true`。

### 5.3 设备识别

- `game.GetDevice()` 返回 **EnumItem（不是字符串）**，元表只放行 `Name` / `FullName` / `EnumType`；`tostring()` 拿不到名字。
- `Enum.Device` 取值：`KeyboardAndMouse` / `Mobile` / `Controller` / `MobileController`。
- 适配层策略（`detectDevice`）：**只有确认为 `Mobile` / `MobileController` 才走触摸分支**，其余（PC / 手柄 / 读不到）一律按 PC —— 键盘方案在任何设备上都可用。
- 可用 `C.device='auto' | 'keyboard' | 'mobile'` 强制分流（`'mobile'` / `'keyboard'` 跳过读取，直接指定）。

## 6. 画布与坐标接口

- 尺寸来源：`game.GetUICanvasSize()` → `CW, CH`。
- 逻辑视口：`640×480`，原点左上、Y 向下（核心口径）。
- 平台画布：原点**左下、Y 向上**。
- 适配层换算：`S = min(CW/640, CH/480)`，`OX=(CW-640*S)/2`，`OY=(CH-480*S)/2`，等比居中，宽屏两侧留黑边。
  - 世界→画布：`canvasX = OX + x*S`，`canvasY = OY + (480 - yBottom)*S`（矩形用底边转换）。
  - 画布→世界：必须**翻一次 Y**（`toWorld`）。
- 每个弹幕函数**不要**再单独加一套 Y 翻转；核心已统一做脚本坐标到显示坐标的转换。

## 7. 关卡全局自定义变量接口

- 读取：`game.GetGlobalCustomVariableValue(Enum.CustomVariableEntityType.Level, name)`
  - 安全写法：`M.enumValue('CustomVariableEntityType', 'Level') or 'Level'`
- 本项目使用两个可选的关卡全局自定义变量：

| 变量名 | 类型/默认 | 作用 |
| --- | --- | --- |
| `SansDifficulty` | 字符串 `original` | 覆盖标题页默认难度；玩家仍可在标题页改选 |
| `SansRound` | 整数，通常不设 | **仅 `C.debug=true`** 时使用的阶段跳转（1=第一份常规攻击，13=中场，14=第二阶段，23=终盘） |

> `SansRound` 只在 debug 模式下读取；正式发布保持 `C.debug=false`。调试模式并不自动无敌。

## 8. 音频接口

配置 `C.audio`，音效 ID 为 0 表示静音；使用的是**已配置音效资产 ID**，不是播放器实例序号、文件路径或模板索引。

| 接口 | 用法 | 说明 |
| --- | --- | --- |
| `game.PlayAudio2D(audioId)` | 播放 2D 音频，返回句柄 `h` | 源码 `lua/music.lua` |
| `game.StopAudio(h)` | 停止指定句柄 | 停 BGM、停短音 |
| `game.IsAudioAlive(h)` | 查询句柄是否存活 | BGM 循环重播判断、短音限流 |

- 存在性判断：`type(game) == 'table' and type(game.PlayAudio2D) == 'function'`。
- 使用 `pcall` 包裹调用，缺资产/无接口时静默降级。
- 场景播放器与 Lua 播放**不要叠放**同一首音乐；Lua 无法停止它没有创建的音频实例。
- **官方客户端没有音频进度暂停接口**：暂停停止声音，继续时 BGM 从头播放。

## 9. 服务器信号与结算接口

### 9.1 客户端发送

| 接口 | 用法 | 说明 |
| --- | --- | --- |
| `game.ServerSignal(name)` | 创建信号对象 `sig` | `name` 默认 `'SansFightSettle'`（`C.settlement.signal`） |
| `sig:AddString(v)` | 追加字符串参数 | **按位置传值**，不能把字段名当第一个实参 |
| `sig:AddInt(v)` | 追加整数参数 | 传整数 |
| `sig:AddFloat(v)` | 追加浮点参数 | 传浮点 |
| `sig:SendSignal()` | 发送信号 | 本地发送成功 ≠ 服务器已结算 |

### 9.2 信号参数（顺序固定）

在**服务器信号管理器**添加信号 `SansFightSettle`，参数按下面**顺序和类型**声明（名字可自定，顺序不能改）：

| 顺序 | 建议名 | 类型 | 含义 |
| ---: | --- | --- | --- |
| 1 | outcome | 字符串 | `kill` 击倒 / `fail` 失败 / `spare` 非原作档饶恕 |
| 2 | hp | 整数 | 剩余战斗 HP |
| 3 | kr | 整数 | 剩余 KR |
| 4 | fightAttempts | 整数 | 累计 FIGHT 阶段计数 |
| 5 | elapsedSeconds | 浮点数 | 本次战斗逻辑秒数（含玩家行动时间） |
| 6 | damageHits | 整数 | 常规伤害命中次数（不含 KR 自燃/撞墙） |
| 7 | difficulty | 字符串 | `original/easy/normal/hard` |

发送策略（`requestSettlement` / `C.settlement`）：
- 只在结局页选择**结算**后发送；失败保持 `fail`，不会被改成胜利。
- 出错后按 `retryDelay=1` 秒重试，最多 `maxAttempts=3` 次；超过后置 `settleStatus='failed'`，可再点击重试。
- 返回成功只表示本地发送完成，UI 显示"等待服务器结束关卡"；**没有服务器回执协议**。

### 9.3 服务器节点图（在沙箱窗口手工连线）

推荐建一个常驻控制物件上的服务器实体节点图 `SansFightSettlement`：

```text
接收 SansFightSettle（读 7 个参数）
  → 获取在场玩家实体列表，长度=1，取唯一玩家实体
  → 检查去重变量 SansSettled（false 才继续）
  → 按 outcome 设置玩家结算成功状态（kill/spare→胜利，fail→失败）
  → 设置最多三条结算展示数据
  → 可选：设置整数排名数值（计时可取 floor(elapsedSeconds*1000)）
  → 结算关卡
```

要点：
- 去重变量 `SansSettled`（布尔，默认 false）防止信号被重复处理；新关卡启动时复位。
- 先设置玩家胜负与展示数据，**最后**才"结算关卡"（该节点会结束整个关卡）。
- 信号是全局广播，只保留一处负责最终结算的监听。
- 玩家实体必须从"获取在场玩家实体列表"取，不能把控制物件或 3D 角色实体直接接到"玩家实体"引脚。
- 当前 7 个参数**不含玩家身份**，多人与权威排行榜不在本版实现内。

## 10. 平台接口关键约束（踩坑清单）

1. **控件默认可能是未激活的**；实例化后父层与叶子都要 `SetActive(true)`、`SetVisible(true)`。
2. **模板包装**：模板可能是"容器 + 叶子"，按叶子接口识别（如 `SetImage` / `text` / `AddCursorEventListener`），并拉伸归一化包装层。
3. **控件身份是小写 `id`**；模板索引（prefab）≠ 运行时 id。
4. **颜色必须转 ColorValue**，整数不能直接写 `imageColor/fontColor/bgColor`。
5. **`SetLocalRotation` 三个参数**，2D 旋转在 Z 轴；只传一个角度会写错轴。
6. **`fontSize` 是整数**；写小数会抛异常并中断整帧绘制。
7. **`raycastTarget` 只用于光标控件**；不要写到普通图片上。
8. **按键监听回调必须保留同一对象**，否则 `RemoveKeyEventListener` 卸载不掉。
9. **不要双推进**：`OnUpdate` 与 `OnLevelUpdate` 不能同时推进战斗。
10. **销毁时清理自建控件，不销毁宿主 root**。
11. **`showCursor` 在 root 上设置**；指针监听依赖光标检测区域。
12. `GetDevice()` 返回 EnumItem 而非字符串；读不到值时按 PC 分支兜底，避免把玩家卡死。

## 11. 本版明确未使用 / 未确认的接口

以下能力**不在本版承诺范围内**（`docs/项目交接与开发说明.md` §13、`docs/部署与设置.md`）：

- 服务器回执协议 / 幂等 token / 权威防作弊 / 可信排行榜。
- 音频进度暂停、音高/播放速度修改 API（不要写不存在的 `SetAudioPitch`）。
- 多人共享战斗、同步血量、独立多人结算（7 个参数不含玩家身份）。
- 断线重连持久化战斗进度（重进从标题页开始）。
- 实体手柄实测验证（只做了官方语义键注册，未验证各平台手柄布局与焦点）。
- 外部 mp3 / 音频通用导入流程、原作音频资产。
- 真机控件预算与设备负载数据（离线全阶段采样创建约 9730 个模拟控件，**不等于真机耗时/帧率**）。
